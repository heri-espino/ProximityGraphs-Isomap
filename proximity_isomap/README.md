# Canonical research area

For EXP-001 through EXP-008, the same numbered slugs appear in [notes](notes/README.md), [code](code/README.md), [figures](figures/README.md), and [results](results/README.md). Each experiment's Markdown note embeds the latest **actual** PNG figure and links to the corresponding metrics, JSON, and NPZ.

Preserved dated research decisions: [history](history/README.md). Mathematical notes and proofs: [notes/mathematics](notes/mathematics/index.md). Original pre-reconstruction scores are historical, not numerically reproduced.

**Recompute:** from the repository root use `./scripts/run_all.ps1 -Push` in PowerShell. This uses Conda and pinned `contrastcolors`, and creates new immutable result folders. See [AGENTS.md](../AGENTS.md) for the required note/figure/result documentation rule.
