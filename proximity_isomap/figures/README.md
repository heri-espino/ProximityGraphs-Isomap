# Experimental figures

The [ContrastColors](https://github.com/heri-espino/Colors) `heri` Matplotlib style and Okabe–Ito palette are pinned in `environment.yml`. Each real run saves both `*.png` and `*.svg` to `NNN-short_title/runs/RUN_ID/` and automatically embeds the PNG(s) in the experiment note. Pre-existing `summary.svg` are historical reconstructed charts, not the original projected clouds.
