# Experimental visualizations

Each experiment's figures live in `figures/<NNN>-<slug>/`. Every note links actual files. The included SVG diagrams are **newly drawn from archived rounded numerical summaries** (or conceptual where numeric sources are absent), not copies of the original 3D observations/2D embeddings.

Original 3D/2D PNG and SVG plots from EXP-002–008 are not on GitHub main and cannot be recreated exactly without the older ZIP archive and its NPZ arrays. Restore them under the same numbered folders, record provenance and regenerate by the original plot code after source integration. Do not invent a plot and call it an original run.
