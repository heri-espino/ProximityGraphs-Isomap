# Experiment scripts and configurations

A numbered experiment's code belongs under `code/<NNN>-<slug>/`; reusable importable algorithms stay in `../../src/proximity_isomap/`. Only the EXP-001 original runnable script and configuration are available from the repository in this session.

Source for 002–008 is **pending restoration** from the original integration bundle documented at [archive status](../../experiments/ARCHIVE_INTEGRATION_STATUS.md); a README records what the script should do and what source is absent. **Do not confuse a README with a runnable script.**

The commit includes a small self-contained SVG summary plotting utility in [plot_archived_summary.py](plot_archived_summary.py) that can regenerate numerical-summary charts from tabular values; it cannot reconstruct the missing 3D embeddings.
