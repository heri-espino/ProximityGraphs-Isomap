# ADR-0004 — Journal-first AI handoff and source-backed literature

**Date:** 2026-10-16  
**Status:** Accepted

## Decision

Enforce journal-first reading through `AGENTS.md`: read `journal/README.md` and latest entry, then `AI_HANDOFF.md`, then the current context. Every substantive editing session concludes with a dated append-only journal note and synchronized summaries. Public APIs use NumPy-style docstrings for Sphinx.

Reserve `literature/pdf/` for primary PDF papers, `literature/markdown/` for Docling-derived reading copies, and `literature/references/` for per-paper verified annotations, a cross-paper key-results index, and a canonical BibTeX bibliography. Maintain `literature/MANIFEST.csv` for machine-readable status.

## Alternatives

A single README; journal-only history; AI summary-only state; duplicate reference notes in `notes/`; and mixing unverified Docling extraction with source-checked results. Rejected because they weaken source authority, temporal context or reproducibility.

## Consequences

Updates require more discipline. The workflow can be partially validated in CI but cannot compel every external assistant to comply. Literature extraction must not be mistaken for proof verification. `paper/main.tex` uses the canonical literature BibTeX database.
