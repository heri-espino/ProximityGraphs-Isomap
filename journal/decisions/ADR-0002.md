# ADR-0002 — First graph baseline

**Date:** 2026-10-16  
**Status:** Accepted provisionally

## Decision

First implementation uses undirected radius adjacency `||x_i-x_j|| <= r` with ambient Euclidean edge weights. It does not perform forbidden-region emptiness tests.

## Reasons

Pairwise-local and simple; makes it easy to isolate the effect of connectivity and evaluate exact radius monotonicity.

## Tradeoffs

Equivalent to an existing epsilon-neighborhood construction, hence not novel. Nonuniform sampling and folded manifolds cause sparse regions and shortcuts respectively. Later studies should include empty-region and adaptive baselines.
