# EXP-0001 — Radius filtration on a synthetic Swiss roll

**Status:** implemented exploration; not a confirmatory comparison.  
**Script:** [`run_exp_0001.py`](run_exp_0001.py)  
**Config:** [`configs/exp_0001.json`](configs/exp_0001.json)

## Question

How does changing radius affect component structure and graph-geodesic error when intrinsic distances are known analytically?

## Dataset

Noiseless Swiss roll parameterized by `f(t,h)=(t*cos(t), h, t*sin(t))`, with `t` and `h` uniform within fixed bounds. A flat coordinate is `u(t) = 0.5*(t*sqrt(1+t^2) + asinh(t))`; intrinsic distances in the full parameterized strip are `sqrt((u(t_i)-u(t_j))^2+(h_i-h_j)^2)`.

## Measurement

At each radius, report graph component count, edge count, number of within-component pairs, and RMSE between graph shortest paths and true intrinsic distances **on pairs in the same graph component**. These are descriptive, not comparable without accounting for varying evaluated pair sets: the set of within-component pairs changes with radius.

## Confounds and limitations

- Selection bias: small radii evaluate easier/local pairs, whereas larger radii evaluate more/global pairs.
- Shortcuts across folds can artificially shorten estimated geodesics.
- No embedding is optimized in this first experiment.
- A single synthetic realization does not establish statistical superiority.
- Do not select the radius minimizing this exploratory RMSE and reuse it as an independent test result.

## Next experimental step

Create a held-out, paired benchmark using identical point sets across methods, with evaluation on **all** pairs against true intrinsic distances, plus honest coverage/failure reporting.
