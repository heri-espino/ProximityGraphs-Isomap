# Annotated research references

This directory is not just a citation dump. It is a source-backed evidence index:

- `library.bib`: canonical BibTeX references, used directly by the manuscript.
- `PAPER_TEMPLATE.md`: mandatory format for an annotated paper.
- `<citation_key>.md`: the paper's questions, assumptions, notation, key results, proof ideas, limitations, and relation to this project. Each result has a stable local identifier and exact source location.
- `KEY_RESULTS.md`: a cross-paper catalog of the results most relevant to this research, linking to their full annotations.

In mathematical notes use citations like `[@citation_key]` only when the source has been verified, and link the local note from the result record. A Docling extraction alone is not proof that theorem labels or formulas were transcribed correctly.
